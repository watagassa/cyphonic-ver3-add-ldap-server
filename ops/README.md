# CYPHONIC Operations Daemon

CYPHONIC 証明書発行サービス

## Description

CYPHONIC の証明書発行サービス

OPS では以下のことを行います

- ユーザアカウントの作成
- ユーザ証明書の作成
- サーバ証明書の作成

## Requirement

| 言語/フレームワーク | バージョン |
| :------------------ | ---------: |
| go                  |     1.23.4 |
| CockroachDB         |     23.1.8 |
| Docker              |   20.10.17 |
| docker compose      |      2.7.0 |

## Usage

1. make
2. make run
