# CYPHONIC Connection Management Service Daemon

CYPHONIC 通信管理サービス

## Description

CYPHONIC の通信管理サービス

CMS では以下のことを行います

- NodeにNSを割り当てる
- CommonKeyの作成

## Requirement

| 言語/フレームワーク | バージョン |
| :------------------ | ---------: |
| go                  |     1.23.3 |
| CockroachDB         |     23.1.8 |
| Docker              |   20.10.17 |
| docker compose      |      2.7.0 |

## Usage

1. make
2. make run
